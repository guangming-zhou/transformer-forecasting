## 可重复检查

```powershell
.\.venv\Scripts\python.exe scripts/check_release.py --verify
```

脚本生成 `outputs/_runs/release-check/report.json`（文件大小、SHA256、扫描结果及验证退出码）
和一个独立候选副本，不修改 Git 索引、不上传文件、不删除本地实验结果。
这个清单仅包含明确选定的文件；实际提交时还需用 Git 检查暂存区与清单是否一致。
`.gitignore` 只影响未跟踪文件，若之后已有文件被提交，规则不会自动移除历史内容。

首次推送前检查 `git diff --cached --stat` 和 `git diff --cached`，确认仓库地址、公开范围、
许可证及所有暂存文件。不要强制覆盖已有远程历史。首次 GitHub Actions 运行通过后，
再把本地测试结果与远程 CI 状态区分展示。
